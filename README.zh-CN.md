# Apple Music Auto Import

> 当前为 `0.3.0-rc.23` 开发快照，仍有部分歌曲测试未通过。现阶段优先解决当前开发电脑上的使用问题，全新电脑兼容性尚未验证；此版本不是稳定正式版。

这是一个 Windows 工具，用来把本地音频、现场版、翻唱版或受支持的网页视频链接整理后导入 Apple Music。

它可以自动下载音频、转换为 M4A、搜索歌曲资料，并在导入前显示完整预览。你可以在预览页修改歌名、歌手、专辑、年份、封面、作曲、作词、编曲和歌词，最终以你的修改为准。

程序会先从页面标题和简介中分离歌曲名与当前演唱者，再查询原版歌曲。当前演唱者与原唱不一致时会自动按翻唱处理：歌曲艺术家使用当前演唱者，专辑艺术家及专辑、年份、封面、歌词和词曲编资料继承原版。

写入 Apple Music 的歌词只保留歌词正文，并在最后显示一行 `作词：姓名`；出品、制作、乐手、录音、混音、企划和营销等名单不会混入歌词。时间轴来源中被拆成一两个字的短句会先合并为自然歌词行。

## 下载和启动

推荐下载 GitHub Release 中的：

`AppleMusicAutoImportPortable.zip`

1. 完整解压压缩包，不要直接在压缩包内运行。
2. 先双击 `Check-Environment.vbs` 检查运行环境。
3. 双击 `Start-AppleMusic-Auto-Import.vbs` 启动工具。
4. 粘贴视频或播放列表链接，或者选择本地音频。
5. 在导入前预览页确认并修改资料。

电脑需要安装 Python 3.10 或更新版本。程序首次运行时会在当前 Windows 用户的本地资料目录中创建独立环境，并询问是否安装经过测试的固定版本组件。

程序不会写死作者电脑的用户名或路径。它会读取当前 Windows 账号自己的“音乐”目录，并寻找 Apple Music 和旧版 iTunes 的常用自动导入位置。如果使用者在 Apple Music 中改过媒体目录，第一次选择对应的 `Automatically Add to Apple Music` 文件夹即可，之后程序会记住。

## Windows 要求

- Windows 11 x64
- Apple Music for Windows
- Python 3.10 或更新版本
- 首次使用前至少打开一次 Apple Music，让它创建媒体目录
- 联网功能需要可正常访问相应的视频与音乐资料网站

本项目目前只支持 Windows。macOS 版 Apple Music 的导入方式不同，暂未提供。

## 全新电脑可能出现的差异

- 当前正式支持范围是 Windows 11 x64 与 Microsoft Store 中的新版 Apple Music。ARM64 Windows 和旧版 Apple Music 暂未验证。
- 启动器优先使用 Windows PowerShell 5.1，找不到时会尝试 PowerShell 7。
- Windows 用户名、系统语言、“音乐”目录重定向到 OneDrive，以及解压路径含空格或中文都已兼容。
- 设置、日志和独立 Python 环境会保存在每个 Windows 用户自己的 `%LOCALAPPDATA%\AppleMusicAutoImport`，不会沿用作者电脑或其他 Windows 账号的资料。
- 必须先完整解压。若 Windows 阻止运行，请右键原始 zip，打开“属性”，勾选“解除锁定”，然后重新解压。
- 公司或学校电脑可能用 AppLocker、组策略或安全软件禁止未签名脚本，这类限制不能由普通程序绕过。
- 在线识别和网页音频下载会受到地区、代理、网络与网站限制影响；在线来源不可用时，本地音频仍可手动填写资料后导入。
- 需要登录、年龄验证、会员权限、DRM、私人权限或地区许可的网页媒体不保证能够下载。
- 安全软件可能阻止临时脚本、Python 或 FFmpeg；`Check-Environment.vbs` 会检查常见缺项和目录权限，但公司级限制仍需该电脑的管理员处理。
- 本地导入成功不等于云同步成功。云端歌单需要 Apple 账号、订阅和“同步资料库”都正常。

## 注意

- 程序导入的是本地音乐。能否同步到云端资料库或加入云端歌单，由 Apple Music 的登录、订阅和云资料库状态决定。
- Apple Music 登录失败或“更新云端资料库”失败，不是音频标签程序能够绕过的问题。
- 现场版、翻唱版和未正式发行歌曲的公开资料可能不完整，请以导入前预览为准。
- 请只下载和使用你有权使用的音频或视频。
